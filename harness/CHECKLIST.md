# Wilco checklist

One row per flow. `State` is rewritten by `./harness/run.sh --update-checklist`
on every run; `Proven by` is written by hand when a check has been watched
going red.

States: **red** the flow is broken · **green** passed AND proven · **unproven**
passed, never seen failing · **unbuilt** no check yet.

A run exits non-zero on any red or unbuilt row.
